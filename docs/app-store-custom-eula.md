# InkSlate — App Store Connect Custom EULA

**How to use this file**

1. Open App Store Connect → **Apps** → **InkSlate** → **App Information** → **License Agreement** → **Edit**
2. Select **Apply a custom EULA to all chosen countries or regions**
3. Copy everything below the line **--- COPY FROM HERE ---** and paste into **Custom License Agreement**
4. Select all countries/regions where InkSlate is sold, then **Save**

**Also confirm in App Information:**

- Privacy Policy URL: `https://sirlwaldron.github.io/InkSlate/privacy.html`
