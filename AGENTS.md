# InkSlate Agent Guidelines

## Git & GitHub Remote Policy (STRICT)
- **CRITICAL**: NEVER push to GitHub, run `git push`, or update any remote repository unless the user explicitly and unambiguously requests it in their prompt (e.g. "push to github", "git push").
- All commits must remain local.
- Staging and local commits are allowed when helpful, but remote synchronization (`git push`, `gh pr create`, etc.) is strictly forbidden without explicit permission.
